# SEGMENT — сборка

Публичный репозиторий сборки для лаунчера SEGMENT.

- **Releases** — версии сборки. Лаунчер берёт `pack.json` из последнего релиза (`releases/latest`), качает моды и конфиги и обновляет игроков сам.
- **servers.json** — адреса серверов для «Сразу заходить на сервер». Пока список пуст, настройка в лаунчере серая.
- **info/** — раздел «Информация» в лаунчере: `seasons.json` (Канон по сезонам), `persons.json` (Персонажи), `other.json` (Дополнительно). Правится так же, без релиза.
- **news.json** — новости в лаунчере (меню → Новости). Редактируйте прямо на GitHub, релиз для этого не нужен.
- **credits.json** — список авторов и разработчиков, который показывается в лаунчере (Настройки → Лаунчер). Редактируйте прямо здесь на GitHub — у игроков обновится при следующем запуске.

## Как выпустить новую версию сборки

1. Обновите сборку в CurseForge (`SEGMENT_2.0`), при желании — новости в `packtool.json` в папке сборки.
2. Запустите `Собрать релиз.bat` из папки лаунчера и введите номер версии.
3. На открывшейся странице GitHub создайте релиз с тегом `v<версия>` и перетащите туда **все** файлы из папки `dist`.

## Публикация через git (без ручной загрузки)

Можно не создавать релиз вручную: положите все файлы из `dist` в папку `release/` этого репозитория (заменив старые), при желании добавьте `release/NOTES.md` с описанием, и отправьте в `main` (или загрузите через «Add file → Upload files» на сайте). GitHub Actions сам создаст релиз `v<версия>` и сделает его последним.

## Новости (news.json)

1. Откройте `news.json` на GitHub и нажмите карандаш (Edit this file).
2. Добавьте новость **в начало** списка `news` — первая в списке показывается первой:

```json
{
  "news": [
    {
      "title": "Заголовок",
      "date": "20 ноября 2026",
      "author": "Команда SEGMENT",
      "image": "https://ссылка-на-картинку.png",
      "text": "Первый абзац.\n\n## Подзаголовок\n- пункт списка\n- ещё пункт"
    },
    { "title": "Предыдущая новость", "text": "..." }
  ]
}
```

- Обязательны только `title` и `text`; `date`, `author`, `image` — по желанию.
- В `text` перенос строки пишется как `\n`, пустая строка (`\n\n`) — новый абзац, `## ` в начале строки — подзаголовок, `- ` — пункт списка, `![подпись](images/имя.png)` отдельной строкой — картинка внутри новости.
- Между новостями ставится запятая, после последней — нет. Если в файле ошибка, лаунчер оставит прошлые новости.
- Картинку удобно загрузить в папку `images/` этого репозитория и взять ссылку вида `https://raw.githubusercontent.com/KineSerpure/segment-pack/main/images/имя.png`.
- **Commit changes** — у игроков новости обновятся при запуске лаунчера или открытии раздела «Новости» (GitHub может задержать правку на несколько минут).

Окно с правилами при запуске — необязательное поле `notice` рядом с `news`:
`"notice": { "id": "rules-1", "title": "Правила сервера", "text": "..." }`. Окно показывается, пока игрок не отметит «Не показывать снова»; чтобы показать его всем заново, смените `id`.

## Информация (папка info/)

Каждая запись в лаунчере выглядит как досье: цветная плашка с заголовком, блок полей (сезон, автор, дата, свои поля) и текст. Три файла — три вкладки:

### info/seasons.json — Канон

```json
{
  "seasons": [
    { "season": "Сезон 0", "articles": [
      { "title": "До Разлома", "date": "1 сентября 2026", "author": "Летописец",
        "fields": [["Место", "Западный мыс"]],
        "text": "## Мир до катастрофы\nТекст..." }
    ] },
    { "season": "Сезон 3", "articles": [] }
  ]
}
```

- `season` — название вкладки, вкладки идут в порядке списка. Последний сезон подсвечен синим градиентом как актуальный; чтобы подсветить другой — `"current": true`.
- `articles` — записи: `title`, `text`, по желанию `date`, `author`, `image`, `fields`.

### info/persons.json — Персонажи

```json
{
  "persons": [
    { "name": "Арден", "role": "Хранитель маяка", "show": "skin", "skin": "skins/arden.png", "arms": "тонкие",
      "fields": [["Фракция", "Без фракции"], ["Возраст", "54"]],
      "text": "## Кто он\nПоследний смотритель маяка." },
    { "name": "Кайра", "role": "Глава Дома Ворона", "show": "image", "image": "images/kaira.png", "text": "..." }
  ]
}
```

- `show` — что показывать: `"skin"` — 3D-модель, `"image"` — картинку.
- Модель: `skin` — PNG-скин 64×64 в папке `info/skins/` **или** `nick` — ник с лицензией (скин у Mojang). Форма рук: `"arms": "толстые"` или `"arms": "тонкие"` (можно и по-английски: `"model": "classic"` / `"slim"`); без поля — определяется по скину. Под моделью в лаунчере она показывается, но игроки её не меняют.
- Картинка: `image` — файл в `info/images/` или полная ссылка.

### info/other.json — Дополнительно

```json
{
  "other": [
    { "title": "Что мы ждём от игроков", "author": "Администрация", "text": "## Отыгрыш\n- Держитесь роли" }
  ]
}
```

### Общее

- `fields` — строки досье в нужном порядке: `[["Название", "значение"], ...]`. Необязательно.
- Текст оформляется как в новостях: `\n` — перенос, `\n\n` — абзац, `## ` — подзаголовок, `- ` — пункт, `![подпись](images/файл.png)` отдельной строкой — картинка (по нажатию открывается крупно).
- Пути `skins/...` и `images/...` считаются от папки `info/`. Загрузить файл: откройте папку `info` на GitHub → «Add file» → «Upload files» (для новой папки в имени файла напишите `skins/arden.png`).
- Если в файле ошибка, лаунчер оставит прошлую версию.

## Уведомления

Когда в `news.json` или в файлах `info/` появляется новая или изменённая запись, у игроков справа сверху всплывает уведомление «В категории «…» произошли изменения!» — нажатие открывает эту запись. Для «Сборки» уведомление приходит, только если нужно установить обязательные моды.

## Серверы (servers.json)

```json
{
  "servers": [
    { "name": "SEGMENT", "address": "play.segment.ru" },
    { "name": "Резерв", "address": "95.31.12.40:25565" }
  ]
}
```

- `name` — название в списке, `address` — домен или `IP:порт` (порт можно не писать, если он 25565).
- Игрок включает «Сразу заходить на сервер» и галочкой выбирает, куда заходить при запуске. Первый сервер в списке выбран по умолчанию. Все серверы списка также появляются в «Сетевой игре».
- Пункт «Иной путь» — игрок вписывает свой адрес; перед запуском лаунчер предупреждает, что сборка сделана для серверов SEGMENT.
- Неверные адреса лаунчер пропускает. Правка приходит игрокам при запуске лаунчера или в течение 3 минут, если он открыт.
