# SEGMENT — сборка

Публичный репозиторий сборки для лаунчера SEGMENT.

- **Releases** — версии сборки. Лаунчер берёт `pack.json` из последнего релиза (`releases/latest`), качает моды и конфиги и обновляет игроков сам.
- **credits.json** — список авторов и разработчиков, который показывается в лаунчере (Настройки → Лаунчер). Редактируйте прямо здесь на GitHub — у игроков обновится при следующем запуске.

## Как выпустить новую версию сборки

1. Обновите сборку в CurseForge (`SEGMENT_2.0`), при желании — новости в `packtool.json` в папке сборки.
2. Запустите `Собрать релиз.bat` из папки лаунчера и введите номер версии.
3. На открывшейся странице GitHub создайте релиз с тегом `v<версия>` и перетащите туда **все** файлы из папки `dist`.

## Публикация через git (без ручной загрузки)

Можно не создавать релиз вручную: положите все файлы из `dist` в папку `release/` этого репозитория (заменив старые), при желании добавьте `release/NOTES.md` с описанием, и отправьте в `main` (или загрузите через «Add file → Upload files» на сайте). GitHub Actions сам создаст релиз `v<версия>` и сделает его последним.
